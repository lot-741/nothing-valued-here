# nothing-valued-here

Transcriptions from 741 boxes of records, bought at a storage lien auction in Anchorage, Alaska.

The film in these boxes is lost to vinegar syndrome. What survives is audiotape, shot logs, typed reports, payroll and field notebooks. I'm describing the boxes one at a time.

**Described so far:** Box 41.

## Layout

- `inventory/inventory.csv`: the full inventory, including the "Repeat to" column.
- `box_041/`: start with `box_041/INDEX.md`.
- `box_041/signs/`: Variant Three and stone 31 as structured data.
- `tools/compare_signs.py`: compares the two.
- `NOTES.md`: my own running notes.
- `SOURCES.md`: links for everything marked public record.
- `SHA256SUMS.txt`: checksums for every file.

```
python tools/compare_signs.py
```

## If something doesn't line up

Open an issue with the box and sheet number. Some of the numbers in here don't agree with each other. I've left them as I found them.
